# E-commerce Sales Analysis Dashboard Using Excel

## Project Overview
This project focuses on analyzing e-commerce sales data and creating an interactive Excel dashboard to understand sales performance and business insights.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization

## Dashboard Features
- KPI summary for sales performance
- Monthly sales trend analysis
- Category-wise sales analysis
- Region-wise sales analysis
- Payment method distribution
- Interactive filtering using slicers

## Key Insights
- Analyzed sales trends over time
- Identified high-performing categories and regions
- Compared sales distribution across different segments
